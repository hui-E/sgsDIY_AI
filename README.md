# 三国杀AI自动DIY

一个免费让AI自创三国杀武将卡的编辑器：填写武将名称，ai自动设计，自动获取相关图片，进入排版，导出一张固定 `1425 × 2048` 的卡面图片。

## 功能介绍

### 武将AI生成

- 根据武将名称，ai自动设计三国杀技能。
- ai生成后，自动获取角色对应图片（支持更换）。
- 可在ai设计的基础上，对势力、人名、称号、图片、技能名、技能描述进行编辑。
- 支持填写“武将设计要求”。约束ai生成。
- 支持保存提示词和模型至预设。

### 随机抽取（解决面杀的部分随机问题）

- 从多个自定义条目中抽取任意个结果
- 已内置4花色和13个点数的抽取
- 支持放回和不放回两种抽取模式
- 支持编辑每个条目的权重
- 抽取有音效（可静音）



## API获取教程

### 免费大模型服务

- 接口支持OpenAI兼容协议(`/chat/completions` 接口)，以[智谱](https://www.bigmodel.cn/apikey/platform)为例。
- 点击新建API key，名称可以随便取。
- 复制新建的API key，回到软件的AI配置
- API地址填https://open.bigmodel.cn/api/paas/v4
- key填刚刚复制的，模型名可进入[体验中心](https://www.bigmodel.cn/trialcenter/modeltrial/text)挑选。（比如可选“GLM-4.5-Flash”）
- <img src=".\素材\1788094079205.png" alt="image-20260830173147986"  />
- 一般来说免费模型里，越蠢的模型生成速度越快，越聪明的越慢，热门模型又不稳定。
- 建议去[魔塔](https://www.modelscope.cn/register?inviteCode=hueims&invitorName=hueims)拿key，目前（2026.9.2）每天赠送200魔粒，可免费调用100次DeepSeekV4Pro，这些好模型生成的质量和指令遵循度都不是长期免费不限量模型可以比的。

### 免费图片服务

- 打开[接口盒子](https://www.apihz.cn/api/apihzimgbaidu.html)，找到登录/注册。
- 登录注册成功后即可复制服务ID与key。
- 回到软件AI配置，填入ID与key



## 额外想说

- AI生成页面，武将名的填写可以带上作品名，如“熊出没熊大”、“火影忍者的卡卡西”、“《海贼王》路飞”。

- ai有什么臭毛病可在AI配置-武将设计要求内约束。

- 已经内置了如下提示词，相同类型提示词无须再重复，

- ```
  '1. 技能数量不超过3个。',
  '2. 每个技能名称严格为两个汉字；全部技能描述合计总字数不超过300字。',
  '3. 参考人物原作百科设定，技能贴合人物能力；',
  '4. 技能文本严格遵循三国杀官方技能表述规范，使用官方术语。',
  ```
  
- 获取模型列表受限于官方的更新，不一定全，有时要去模型服务商官网查看，手动输入模型名。
- 仓库素材文件夹有一些最终生成效果，包括图片在内全部都是一键生成，一点都没改。
