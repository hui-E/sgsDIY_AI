# 三国杀武将 DIY

一个让用户自创三国杀武将卡的编辑器：录入武将信息，进入排版，导出一张固定 `1425 × 2048` 的卡面图片。

## 运行（Web 版）

```bash
node server.js 5173
```

浏览器打开 <http://localhost:5173/>。

- 直接使用：填信息 → 选图 → 下一步 → 拖动/缩放排版 → 保存
- 演示模式（跳过编辑、直接进排版）：<http://localhost:5173/?demo>

## 项目结构

- `docs/`：需求文档、开发计划
- `素材/`：原始素材（势力立板、`miscellaneous.png`、成品参考）
- `public/`：Web 应用（HTML / CSS / Canvas 渲染 / 手势 / 导出）
- `tools/`：素材分析 / 切片脚本、交互与导出自动化测试（Playwright + Edge）

## 功能要点

- 势力：魏 / 蜀 / 吴 / 群 / 晋（不含“神”）
- 技能：动态增删，1 ~ 3 个
- 血量：0 ~ 10（勾玉自动排布、可换行）
- 排版：拖动名称 / 称号 / 武将图，双指缩放武将图
- 技能框：自动对齐各自技能描述首行，不可手动移动
- 导出：固定 `1425 × 2048` PNG，web 端下载或分享
